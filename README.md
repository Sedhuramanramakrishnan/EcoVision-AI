# EcoVision AI ♻️

## About the Project
EcoVision AI is a computer vision project
that detects everyday objects in images
and provides waste-sorting guidance.

## Features
- Upload images for object detection
- View detection results
- Explore dashboard insights
- Get waste-sorting guidance
- Export reports

## Technologies Used
- Python
- YOLOv8
- OpenCV
- Streamlit
- Pandas
- Pillow

## How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Start the application:

   streamlit run app.py
